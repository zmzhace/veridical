## 已交付的生产约束

1. `/v1` 与研究 `/api` 分离；默认启动生产配置且缺配置失败。
2. 不可覆盖制品、独立 reviewer、publisher 发布、撤回/回滚、显式 canary、审计追责。
3. SQLite 事务与租户复合键、内容加密、事件 HMAC 链、制品/指针签名、外部检查点和备份工具。
4. 持久化队列、幂等键、会话互斥、期限/租约、取消和中断恢复；不自动重复不确定任务。
5. 成功会话的零外部调用重执行；环境、模型、工具与输入变化导致明确失败，而不是悄悄调真实服务。
6. 自动生成新提示词候选并评测，保留来源；不修改基线、不写共享技能、不改权限、不自行审批或发布。
7. 请求/响应/上下文/步数/队列/速率/存储阈值；生产供应商凭据由配置决定，不接收业务请求指定的密钥或任意地址。

## 未验证或仍需业务方完成

- Docker daemon 在本机不可用；Dockerfile 未实际构建/运行。独立 Node 目录验证不能替代 Linux 容器验证。
- 真实供应商接口、其模型版本是否真正固定、限流/计费语义、业务效果及不确定输出的安全性。
- 真实只读业务工具的正确性、权限与数据隔离。目前只内置无副作用 echo/finish。
- 目标机器峰值负载、长期稳定性、磁盘异常、断电、备份异地保存、恢复时间与恢复点目标。
- TLS、secret manager、人员权限分工、告警接入、生产值守、真实数据保留/擦除策略。
- 任意业务写工具的事务/幂等/补偿；多主机 HA；在线密钥轮换；自动归档清理；独立 WORM 锚定。

审批与加密不能替代这些部署和业务验收。上线操作顺序与限制见 [生产运维手册](production-profile.md)；接口请求体见 [API 工作流](production-api.md)。
